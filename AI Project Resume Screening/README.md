📄 AI Resume Screening System

An intelligent resume screening system that leverages Artificial Intelligence and Natural Language Processing (NLP) to automate candidate shortlisting. This project analyzes resumes and matches them against job descriptions to identify the most relevant candidates efficiently.

🚀 Features
Automated resume parsing and data extraction
Keyword and skill matching with job descriptions
Ranking and scoring of candidates based on relevance
Support for multiple resume formats (PDF, DOCX, etc.)
User-friendly interface for uploading and screening resumes

🧠 Tech Stack
Python
Machine Learning / NLP (e.g., Scikit-learn, NLTK, SpaCy)
Pandas & NumPy
Flask / Streamlit (for web interface)

📊 How It Works
Upload resumes and job description
System preprocesses and extracts key information
Applies NLP techniques to compare skills and experience
Generates a score and ranks candidates accordingly
